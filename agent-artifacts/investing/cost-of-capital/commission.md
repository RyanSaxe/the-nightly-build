## Why this is the next prerequisite

The published curriculum has, in order, built the three financial statements and
then return on invested capital:

- how-a-business-earns-a-profit (income statement, margins)
- what-a-company-owns-and-owes (balance sheet, book value)
- profit-versus-cash (cash flow, accrual vs cash)
- return-on-capital (ROIC)

The ROIC lesson closed on the value-creation test: ROIC only creates value when
it clears "what a company's own regulators call fair" — the hurdle. But the
course has not yet taught the hurdle itself. **Cost of capital is that missing
foundation**: the opportunity-cost return investors require, the rate ROIC must
beat for growth to create rather than destroy value. It is the exact next
prerequisite the ROIC lesson leaves dangling, and it sets up valuation
(discounting future cash flows) in later lessons.

## Angle and required contribution

Teach cost of capital as opportunity cost made concrete: money has a required
return set by the next-best use at comparable risk, so a dollar earning below
that return is losing value even while it "makes a profit." Build to the weighted
average cost of capital (WACC) as the blend of the cost of debt and the cost of
equity, and connect it back to the ROIC-vs-hurdle test the last lesson set up.
Teach the concept so it transfers to any investment, not a single company
walkthrough. Use a concrete worked example (a company or a simple numeric case)
only where it makes the idea real; do not default to a company tour.

The reader finishes able to state what return a specific business must earn to
create value, and why, and to see cost of equity as a required return (not a
cash expense the way interest is). Cover the cost of debt (after-tax, because
interest is deductible), the cost of equity (required return for bearing equity
risk, and the standard tool for estimating it), and how they weight into WACC.
Note honestly what the estimate cannot pin down (cost of equity is estimated, not
observed) rather than implying false precision.
