# Revision 01 — corrected the citation URL for source 14 (Sazawal 2006, Pemba)

Source 14 (the Sazawal et al. iron/folic-acid trial in Pemba, cited for the
"iron is not risk-free in every setting" point) linked to a Europe PMC REST API
query:

> https://www.ebi.ac.uk/europepmc/webservices/rest/search?query=Sazawal...&format=json&resultType=core

That is the endpoint the researcher used to pull the abstract text. It returns a
JSON payload, not a reader-facing article page, so it passed the automated
link check (HTTP 200) but is not a usable source link for a reader.

Replaced it with the stable record for the same paper:

> https://pubmed.ncbi.nlm.nih.gov/16413877/

Verified to be the same study — Sazawal S, Black RE, Ramsan M, et al.,
"Effects of routine prophylactic supplementation with iron and folic acid on
admission to hospital and mortality in preschool children in a high malaria
transmission setting," Lancet 2006 (Pemba, Zanzibar) — and consistent with the
PubMed citation style the article's other primary sources already use. Only the
`href` changed; the source's `data-nb-kind`, its displayed title, the claim it
supports, and every figure remain the same.

Verification: `nb check --revision` and the full `nb check --pr` proof pass with
link checking; the new URL resolves to the correct article record.
