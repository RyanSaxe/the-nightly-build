- editorial-direction.md (artifact root) — house standard, press voice, `article` template identity, series prompt
- commission.md (artifact root) — the tool, what it changes, and the shapes recent expert-tools pieces should break
Output: writing-coach/01/voice-guide.md

Focus: A practitioner tool piece (1200-3000 words) for an ML-engineer reader,
proving a tool's value with one concrete example, not a tutorial. Study
exemplars who write about developer tools with precision and a working example
(the Simon Willison / Julia Evans / Mitchell Hashimoto register). Calibrate for
concrete, implementation-anchored prose that names the tool and the work in
headings. Record from the commission that headlines must name the tool and the
work, and mark the recent "Behind the single command sits an NNN-line script"
opener as "do not reuse".
