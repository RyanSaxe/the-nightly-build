Reinforcement Learning

Moving at random half the time, Q-learning still learns the optimal arrows

Its update differs from SARSA's in one term: it takes the next cell's largest estimate, whatever move the agent makes there.

17 min read2026-11-05

Why this matters

Monte Carlo control changes its estimates only when an episode ends. With an ε-greedy policy it can rest only at the best ε-soft policy, whose arrows stop being optimal once ε reaches 0.33. TD prediction updates after every move instead. Written for action values, its target needs the estimate of one move in the next cell. Taking the move the agent will make there gives SARSA, and taking the move with the largest estimate gives Q-learning. These are the two basic methods of TD control. You will derive which action values each target settles on, and see why Q-learning ends on the optimal arrows while its agent keeps moving at random. DQN, which a later lesson builds, keeps Q-learning's target and replaces the table with a neural network.

The random move that only SARSA's target uses

Take one move on the grid with ε = 0.5. The agent is in cell 9 and aims up. It lands in cell 5, next to the pit, and receives −1. Suppose its estimates in cell 5 are the optimal policy's action values: 0.06 for up, −15.93 for right into the pit, −3.58 for down and −0.29 for left. Its estimate for aiming up from cell 9 is −1.01, the optimal value too. Before it updates anything, the agent draws its next move from the ε-greedy policy. Half the time that draw is uniformly random, and this time it comes up right.

SARSA's target uses the estimate of the move the agent will make next, discounted by 0.9: -1 + 0.9 \times (-15.93) = -15.34. With a step size of 0.1, the estimate for aiming up from cell 9 falls from −1.01 to −2.44. Q-learning's target uses the largest estimate in cell 5, which belongs to up: -1 + 0.9 \times 0.06 = -0.95. Its estimate barely moves, to −1.00.

If the draw had picked up, the greedy move, both targets would have been −0.95. The two methods disagree only when the next move is not the greedy one. With ε = 0.5 the agent in cell 5 aims right one time in eight, and each time SARSA counts that move against aiming up from cell 9. Q-learning never counts it.

The update rules differ in one term

Both methods update the pair the agent just left, after every move, with the TD update written for action values. Call b the move in the next cell whose estimate enters the target.

SARSA's update reads all five of S_t, A_t, R_{t+1}, S_{t+1} and A_{t+1}, which gives the method its name.1 Rummery and Niranjan proposed the update in 1994, in a more general form for neural networks.2 Watkins introduced Q-learning in his 1989 thesis.3

Sutton and Barto's pseudocode also orders one step differently: SARSA draws its next move before the update and Q-learning after it.1 Q-learning's target never uses that move, so the code below can draw it before the update in both methods, which leaves b as the only difference. Rerunning Q-learning in the book's order changed no conclusion below.

td_control.py runs both methods. It calls td0 from estimators.py, unchanged, on (cell, move) pairs numbered as in mc_control.py. Each pair's step size is therefore N(s, a)^{-0.7}, where N(s, a) counts that pair's updates. The variable b is the b of the update, and the one line that sets it is the only code that depends on the method. G adds up the discounted return the agent earns in the episode.

What each target averages to

An update moves an estimate part of the way toward its target, so the estimates stop drifting when each one equals the average of its target. To find where that happens, hold the estimates fixed and average the target over one move from the pair (s, a). The slip rule draws the landing cell s'. For SARSA, the policy \pi that the agent follows draws the next move a'.

Suppose every estimate equals this average. Then Q satisfies the equation that defines q_\pi, the action values of \pi. Each q_\pi(s, a) is \sum_{s'} P(s' \mid s, a)\,[R(s') + \gamma\, v_\pi(s')], and v_\pi(s') is \pi's average of the action values in s'. For each \pi the equation has one solution, because its right side shrinks the largest gap between two sets of estimates by a factor of \gamma. So SARSA's estimates can rest only at the action values of the policy that makes its moves.

That policy is ε-greedy with respect to Q itself, so its average in s' puts 1 - \varepsilon on the largest estimate and \varepsilon/4 on each of the four. The condition for SARSA's estimates to rest becomes the following.

The best ε-soft policy's action values \tilde q satisfy this equation. Each \tilde q(s, a) values the landing cells at \tilde v_*, and \tilde v_*(s') is exactly this ε-greedy average of \tilde q in s'. The right side again shrinks gaps by \gamma. Its ε-greedy average weights the largest estimate and the four estimates by amounts that add to 1, and as in value iteration none of these moves by more than the largest per-move gap. So \tilde q is the only solution. SARSA with a fixed ε can rest only where ε-greedy Monte Carlo control rested, at the best ε-soft policy. At ε = 0.5 that policy's arrow at cell 9 turns left or down.

Singh, Jaakkola, Littman and Szepesvári prove that SARSA reaches this point with probability 1 when its step sizes shrink.4 They prove it for discounted tasks that never end.4 Episodes on the grid end at the goal or the pit, so for SARSA the runs below are the evidence.

Q-learning's average target contains no \pi.

Write q_*(s, a) for the action values of an optimal policy, \sum_{s'} P(s' \mid s, a)\,[R(s') + \gamma\, v_*(s')]. The Bellman optimality equation says that v_*(s') is the largest of the q_*(s', a'), so q_* satisfies the condition for Q-learning's estimates to rest.

Its right side shrinks gaps by \gamma, as value iteration's backup did, so q_* is its only solution. Q-learning's estimates can rest only at q_*, whatever policy makes the moves. That policy decides only which pairs get updated and how often, and an ε-greedy agent that starts each episode in a random cell keeps updating all of them. Watkins and Dayan prove that Q-learning reaches q_* with probability 1 if every pair is updated infinitely often.5 Each pair's step sizes must also have an infinite sum and a finite sum of squares, the two conditions TD prediction used,1 and the step size N(s, a)^{-0.7} in td_control.py meets both. Their proof also lets the updates come from separate stretches of experience, which covers episodes that end and restart.5

SARSA reaches q_* too if ε shrinks toward 0 while every pair is still tried infinitely often, since \pi's average then approaches the largest estimate.4 Expected SARSA puts \pi's average itself in the target, so it moves each estimate the way SARSA moves it on average.1 George John introduced it in 1994,6 and van Seijen and colleagues named it in 2009.7

Learning about the greedy policy while following the ε-greedy one

Control is on-policy when the agent learns the action values of the policy that makes its moves, so SARSA is on-policy. Q-learning learns the action values of the greedy policy while the ε-greedy policy makes its moves. The policy being learned about is called the target policy, and the policy that generates the moves is called the behavior policy.1 A method whose two policies differ is off-policy.1

At ε = 0.5 the two methods part at cell 9

targets.py runs each method 20 times, from seeds 0 to 19, for 100,000 episodes with ε = 0.5. It grades the final estimates against \tilde q from best_soft and against q_*, and counts a run's arrows as right when each one is among the tied best moves.

uv run targets.py needs gridworld.py, control.py, estimators.py, mc_control.py, soft_control.py, exploration.py and td_control.py in one folder. It installs numpy and takes about two minutes on the machine used here.

Q-learning's estimates describe an agent that never moves at random

Each method's estimates describe its target policy, and only SARSA's target policy makes the moves. So only SARSA's estimates predict what its agent earns. Averaged over its ε-greedy moves, SARSA's estimates put cell 9 at −7.09. In the second half of each run, its episodes that start in cell 9 return −7.1 on average. Taking the largest of its four, Q-learning's estimates put cell 9 at −0.98, which estimates what an agent earns by following the optimal arrows and never moving at random. Its own agent's episodes from cell 9 return about −7.3.

From cell 9, Q-learning's agent also earns less than SARSA's. An ε-greedy policy around a set of arrows moves like those arrows on the modified grid that replaces each aim with a random one with probability ε. The direct solve on that grid therefore gives the policy's exact value. Averaged over the runs' final policies, it gives −7.10 at cell 9 for SARSA and −7.30 for Q-learning. Q-learning's arrow at cell 9 aims at cell 5 or cell 10, both next to the pit, and that suits an agent that will not move at random once it gets there. Turning cell 9 left in each Q-learning run's arrows and solving again gives −7.11, within 0.01 of SARSA's. The two runs with a wrong arrow at cell 10 account for that last 0.01.

Problems

1. In the move of Fig. 1, average SARSA's target over the agent's next move in cell 5, with ε = 0.5. How far below Q-learning's target is it?

Answer

The ε-greedy policy aims up, the greedy move, with probability 0.625 and each other way with 0.125. Its average of cell 5's estimates is 0.625 \times 0.06 + 0.125 \times (-15.93 - 3.58 - 0.29) = -2.44, and the average target is -1 + 0.9 \times (-2.44) = -3.20. That is 2.25 below Q-learning's −0.95. It is also Expected SARSA's target for this move.

2. With ε = 0.1, the best ε-soft policy has the optimal arrows. Do SARSA and Q-learning then learn the same estimates? What does SARSA's estimate for right at cell 14 approach?

Answer

No. The arrows agree, but SARSA's estimates still rest at \tilde q for ε = 0.1 and Q-learning's at q_*. For right at cell 14, exploration.py printed −0.37 for the best ε-soft policy, which SARSA's estimate approaches, and 0.61 for the optimal policy, which Q-learning's approaches.

The takeaway

SARSA and Q-learning both apply the TD update to action values after every move. The one difference is which estimate from the next cell enters the target. SARSA uses the move its ε-greedy agent will make, so its estimates rest at that policy's action values. With ε fixed it learns the best ε-soft policy, which at ε = 0.5 aims cell 9 left or down. Q-learning uses the largest estimate, so its estimates rest at q_* whatever the agent does, as long as every pair keeps being updated. It learns about the greedy policy while following the ε-greedy one, which makes it off-policy. Its agent still moves at random, and from cell 9 it earns less than SARSA's.
