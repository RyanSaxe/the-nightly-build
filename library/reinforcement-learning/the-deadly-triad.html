Reinforcement Learning

A problem whose true values are all zero sends off-policy TD's weights to infinity

On Baird's seven-state counterexample, the weights grow without bound only while function approximation, bootstrapping and off-policy training are all present.

18 min read2026-11-12

Why this matters

Linear semi-gradient TD converges when states are updated as often as the policy being evaluated visits them. Off-policy learning gives up that condition on purpose, because a behavior policy decides which states get updated. On a seven-state problem whose true values are all 0, losing it sends linear TD's weights to infinity at every step size. Sutton and Barto name the combination responsible the deadly triad: function approximation, bootstrapping and off-policy training. Given a linear problem and the distribution its updates come from, you will be able to write the expected update as a matrix and tell from its eigenvalues whether the weights grow. Gradient-TD and Emphatic-TD were built to stay stable with all three present, and DQN, later in the course, combines all three with a neural network.

One weight that raises its own target

The smallest case of weights growing without bound has two states and one weight. Sutton and Barto give it as a fragment of a larger MDP. The first state has feature 1 and the second has feature 2, so with weight w their estimates are w and 2w. The first state has one action, which moves to the second with reward 0.1 Fig. 1 draws it.

Suppose w = 10, the discount γ is 0.99 and the step size α is 0.1. Semi-gradient TD(0) updates the first state after its move. The target is 0 + γ · 2w = 19.8 and the estimate is 10, so the TD error is 9.8. The estimate's gradient is the feature, 1, so w rises by 0.1 × 9.8 to 10.98. The second state's estimate rises twice as much, so the next TD error is larger, and the next update takes w to 12.06. Each update multiplies w by the same factor.

Raising w to shrink the first state's error raises its target by more. An agent following the target policy would also leave the second state, and that move's update would pull w back down, as the first problem below shows. Off-policy, the behavior policy can leave the second state by moves the target policy never makes. Their per-move ratio π(a|s)/b(a|s) is 0, so they never change w, and the first move's update repeats with nothing to undo it.1

Sutton and Barto call the fragment not completely convincing, because it is only part of an MDP.1 Baird's counterexample specifies every state.

Baird's counterexample diverges under sampled and expected updates

Baird's counterexample has seven states and two actions (Fig. 2). The dashed action moves to one of states 1–6, each with probability 1/6, and the solid action moves to state 7. Every reward is 0 and γ = 0.99. The target policy π always picks solid. The behavior policy b picks dashed with probability 6/7 and solid with 1/7, so the next state is equally likely to be any of the seven, wherever the agent is.1 Sutton and Barto call the task episodic but draw no terminal state, so we treat it as continuing. Leemon Baird published the original in 1995 as a six-state "star problem," and Sutton and Barto's version is slightly modified.21

Eight weights give the seven estimates. Sutton and Barto draw states 1–6 above state 7 and call them the upper states. Upper state i has the estimate v̂(i, w) = 2wi + w8, and state 7 has v̂(7, w) = w7 + 2w8.1 Every true value is 0, which w = 0 gives exactly.

Off-policy semi-gradient TD(0) is the semi-gradient update with the per-move ratio multiplying each step.1

On Baird's problem, then, the agent learns only from its solid moves, each weighted by 7, and every target is γv̂(7, w). baird.py runs 1,000 steps of TD from Sutton and Barto's start, w = (1, 1, 1, 1, 1, 1, 10, 1) with α = 0.01. Then it runs semi-gradient DP from the same start. One sweep of DP updates every state at once with its expected TD error under π, weighting each state 1/7.1

After 1,000 steps, w8 is 316.75 and the six upper weights lie between 77 and 135. The DP sweeps have no randomness and end at 335.00 and 114.43, on the curves of Sutton and Barto's Figure 11.2 (Fig. 3). Every other seed we tried also diverges, and Sutton and Barto report that the growth occurs for any positive step size, however small.1

Together, the upper states' updates raise state 7's value faster than their own

The TD run and the DP sweeps grow at the same pace because, on average, the TD update is the DP update. From any state s, the ratio turns b's average over actions into π's.

Under b the agent is in each state for 1/7 of the steps, so averaging over states gives the expected update in the form the semi-gradient lesson used for the TD fixed point. Its reward term is 0 here, because every reward is 0. Rewards enter only that term and never A, so whether the weights grow depends on A alone, and a problem with every reward 0 tests it as well as any.

After k steps the expected weights are (I − αA)kw0. Along an eigenvector of A with eigenvalue λ, each step multiplies the weights by 1 − αλ. A positive λ shrinks that component once α is small enough. A negative λ makes the factor larger than 1 for every α > 0, so the component grows at any step size. A complex eigenvalue acts the same way through its real part. baird.py printed two negative eigenvalues, −0.23925 and −0.02218.

Two numbers are enough to see where they come from. Sutton and Barto's start gives the six upper weights the same value, and the expected update treats the upper states alike, so the weights stay equal. Call the value of every upper state U = 2wi + w8, and the value of state 7 H = w7 + 2w8. They start at U = 3 and H = 12.

Follow one upper state's update with TD error δU = γH − U. Its gradient x(i) has a 2 at wi and a 1 at w8, so the update adds 2αδU to wi and αδU to w8. That raises its own value by 5αδU, every other upper value by αδU, and H by 2αδU. A sweep weights each state's update by 1/7, so we count in units of αδ/7. The six upper updates raise each upper value by 5 + 5 × 1 = 10 units and H by 6 × 2 = 12. State 7's update, with TD error δH = γH − H, adds αδH to w7 and 2αδH to w8, which raises H by 1 + 2 × 2 = 5 units and each upper value by 2.

The upper states' TD error is the gap between U and its target γH. Their updates are meant to close the gap, but they raise the target by 12γ = 11.88 for every 10 they raise U, so the gap widens. State 7's update lowers H, but its TD error is (γ − 1)H = −0.01H, too small to keep up. The matrix in the second line, with its 1/7, has eigenvalues −0.23925 and −0.02218 at γ = 0.99, the two that baird.py printed. The other six eigenvalues, 4/7 and 0, belong to directions that leave U and H unchanged, and none of them grows.

Without any one of the three elements, the weights stay bounded

Baird's problem combines three elements. Function approximation computes estimates from weights shared across states. Bootstrapping means "update targets that include existing estimates," such as γv̂(7, w). Off-policy training means "training on a distribution of transitions other than that produced by the target policy."1 DP's uniform sweep is off-policy here, because π's own distribution puts every update on state 7.1 Sutton and Barto call the three the deadly triad, because combining all of them brings a danger of instability and divergence.1

This lesson reads that sentence for linear features, because Tsitsiklis and Van Roy showed on-policy TD(0) with a nonlinear approximator diverging on a three-state chain.3

triad.py takes away one element at a time on Baird's problem, with the same start and α:

  • Off-policy training: the agent evaluates b, the policy it follows. Every ratio is 1, all seven states are still updated equally often, and each expected target is γ times the average of the seven estimates, because b's next state is uniform.
  • Bootstrapping: the target is the scaled return ρGt, as in gradient Monte Carlo. A continuing task has to cut each return off somewhere, and with every reward 0 the return is 0 wherever it is cut.
  • Function approximation: a table with one weight per state, started at the same values, U = 3 and H = 12.

Sutton and Barto remove off-policy training the other way, by updating states in π's distribution, and report that convergence is then guaranteed.1 On this problem that distribution never updates the six upper states, so triad.py evaluates b instead and keeps every state updating.

triad.py, complete

triad.py imports baird.py from the same folder and runs in about 2 seconds.

No removal lets any weight exceed the largest starting weight, 10 with linear features and 12 with a table, over 20,000 sampled steps or 20,000 sweeps. With all three present, the weights pass 1021. None of the removals leaves A with a negative eigenvalue. A 0 in that column belongs to the one direction of weights that changes no value, since eight weights give seven values, and no update moves along it. Fig. 4 follows U and H through the expected sweeps of all four versions.

Evaluating b, every target reads the average of the seven values instead of H alone. Under b, state 7's moves lead to the upper states 6/7 of the time, and with a ratio of 1 those moves now count. State 7's TD error becomes γ times the average minus H, about −7.8 at the start against −0.12 under π, so its update pulls H down faster than the upper updates push it up. In Fig. 4, H drops almost straight down to meet U, and the two values then shrink together toward 0.

With the Monte Carlo target, the errors become −U and −H. Neither reads H any more, so the same 10, 12, 2 and 5 only pull both values to 0, and the weights stop away from 0, along the direction that changes no value.

With a table, an upper state's update moves only its own value, so the upper updates no longer raise H, and U closes on γH. The two values then fall together, slowly, because state 7's TD error is small: A's smallest eigenvalue is (1 − γ)/7 = 0.00143. After 20,000 sweeps both are 9.02.

Problems

1. In the w → 2w fragment, let the agent follow the target policy, and let its move out of the 2w state end the episode with reward 0. Using the matrix A from the semi-gradient lesson, here a single number, decide whether TD(0) is stable.

Answer

Each episode visits both states once, so μ = (½, ½), and the terminal state's feature is 0. Then A = ½ · 1 · (1 − 2γ) + ½ · 2 · (2 − 0) = (5 − 2γ)/2, which is positive for every γ ≤ 1. The expected update w − αAw shrinks w for a small enough α, toward the TD fixed point A−1b, which is 0 because every reward is 0.

2. At what discount does the expected sweep on Baird's problem start to grow?

Answer

Both eigenvalues of a real 2 × 2 matrix have positive real parts exactly when its trace and determinant are positive. For (1/7)[[10, 2 − 12γ], [12, 5 − 17γ]], the determinant 26(1 − γ)/49 is positive for every γ < 1, and the trace (15 − 17γ)/7 turns negative above γ = 15/17 ≈ 0.882. So the weights grow only for γ > 15/17, and below it they stay bounded with all three elements present. Between 5/6 and 15/17 the upper updates widen the gap, since 12γ > 10, but state 7's update, stronger at a smaller γ, keeps up.

The takeaway

Linear semi-gradient TD's expected update is w ← w − αAw, and an eigenvalue of A with a negative real part makes the weights grow at every step size. On Baird's counterexample, uniform off-policy updates fall mostly on the six upper states, and through the shared weight their updates together raise state 7's value, the target they all read, faster than their own values. Evaluate the policy that generates the updates, use the Monte Carlo target, or give each state its own weight, and A has no negative eigenvalue left. Sutton and Barto state the general case as the deadly triad: with linear features, any two of the three can be kept stable, and all three together can diverge.
