Reinforcement Learning

Illegal moves that Q-learning never makes still set its values in the Tower of Hanoi

When only the choice is masked, those moves' estimates stay at 0 inside the target's max, and every legal estimate more than eight moves from the four-disk puzzle's goal settles at −1.

19 min read2026-11-17

Why this matters

A disk in the Tower of Hanoi may never rest on a smaller disk, so the moves an agent may make change with every move it makes. A Q-learning table, though, has a column for every action in every state. The ε-greedy policy was already written for A(s), the set of actions available in state s. Q-learning needs that set in two places: when the agent chooses a move, and when its target takes the largest estimate in the next state. Supplying A(s) from the environment as a vector of 1s and 0s is called action masking. On a four-disk puzzle you will watch an agent that masks only its choice fail, and derive from one equation exactly where its estimates settle instead.

Four of the start's six estimates are never updated

The puzzle starts with four disks stacked on peg 0, largest at the bottom. A move lifts the top disk of one peg onto another peg, and a disk may never sit on a smaller one. The task is to rebuild the stack on peg 2, which takes at least 15 moves. We give the agent six actions, one for each ordered pair of pegs, written 0 → 1 for a move from peg 0 to peg 1. At the start only the smallest disk is free, so A(s) holds two moves, 0 → 1 and 0 → 2. Once the smallest disk sits on peg 1, it holds three (Fig. 1).

Suppose the agent masks its choice: every move it makes is legal, whether it moves greedily or at random. Q-learning updates only the estimate of the move just made, so the estimate of an illegal move is never updated. It keeps its initial value, 0.

Now take one update. The agent is in state 1, with the smallest disk on peg 1, and a random move returns that disk to peg 0, which is the start again. Every move pays −1 except the one that completes the stack, which pays +10, and the discount is the course's 0.9. Suppose every legal estimate already equals its optimal action value: −5.42 for 0 → 1 at the start, −5.88 for 0 → 2, and −5.88 for the move just made. The start's other four estimates are still 0.

Q-learning's target adds the reward to 0.9 times the largest estimate in the next state. Over the legal moves, the target is −1 + 0.9 × (−5.42) = −5.88, so the estimate stays where it is. Over all six, it is −1 + 0.9 × 0 = −1. With a step size of 0.5, that second target raises the estimate of the move just made from −5.88 to −3.44 in one update.

Every state of the puzzle has three or four illegal moves, so a target over all six can read a 0 anywhere. To see what those zeros do to a whole table, the agent needs the puzzle as an environment that reports its legal moves.

The environment sends a fresh mask with every observation

hanoi.py puts the puzzle behind Gymnasium's reset and step, the interface from the lesson on termination and truncation. A state is one integer from 0 to 80, whose base-3 digit k is the peg of disk k, counting from the smallest. The start is state 0, and the goal, every disk on peg 2, is state 80. reset starts each episode in a random state other than the goal, so that learning reaches every legal pair outside the goal. The function legal builds the mask: six int8 entries, 1 for each move that lifts a disk onto an empty peg or a larger disk. Of the puzzle's 486 state-move pairs, 240 are legal.

reset and step return the mask in info under the key "action_mask". Gymnasium's Taxi environment, in which a taxi carries a passenger across a grid, uses the same key and type.1 MaskablePPO, an off-the-shelf agent a later lesson trains, calls a method named action_masks() instead,2 and PettingZoo's multi-agent games put the mask in the observation.3 hanoi.py has that method too, and it returns the mask as booleans.

The environment checker, check_env, steps with random actions drawn without a mask,4 so step has to accept an illegal move. Here an illegal move leaves every disk where it is and pays −1. An agent that masks its choice never makes such a move, so this rule matters only to check_env and to agents that ignore the mask.

The demo at the bottom of hanoi.py runs check_env and then reads the mask at the start. An action is a move's position in MOVES, so the start's two legal moves are actions 0 and 1, and sample(mask=...) draws uniformly between them.5

With only its choice masked, the agent loops beside the start

masked_q.py is Q-learning with the mask read from info, and both kinds of choice use it. A random move comes from sample(mask=...), which gives each legal move ε/|A(s)|, the floor of the ε-greedy policy. A greedy move takes the largest legal estimate. np.argmax over the legal estimates returns a position among them, not a move, so the function greedy maps it back.

The two agents differ only in the target. With target="legal", the max runs over the next state's legal moves, read from the mask that the same step returned.

Gymnasium's tutorial on masking in Taxi masks the same two places.6

With target="all", masked_q.py takes the max over all six estimates. Both agents use a constant step size of 0.5. The lesson on SARSA and Q-learning shrank its step sizes to average out the grid's random slips. No move or reward in this puzzle is random, so a constant step is enough.

leak.py runs each agent five times for 5000 episodes, under a TimeLimit of 100 moves. It grades the legal estimates against q*, which it finds by value iteration over the legal moves. Then it runs each greedy agent from every start. uv run leak.py needs hanoi.py and masked_q.py in the same folder. It takes under a minute on the machine used here.

leak.py, complete

Masked in both places, Q-learning ends within 0.01 of q* on average over the 238 legal pairs outside the goal. In all five runs its greedy agent takes the fewest moves from all 80 starts, including the 15-move solution from the start. Masked only in its choice, it ends 2.4 from q*, and its greedy agent never finishes from the start. After two moves it shuttles the smallest disk between pegs 0 and 1 for as long as it may move (Fig. 2).

In every state nine or more moves from the goal, each legal estimate settles at −1, so all of that state's moves look equally good. np.argmax breaks a tie toward the first legal move in MOVES. That is 0 → 1 at the start and 0 → 2 next, both best moves, and after that 1 → 0 and 0 → 1 over and over. With ties broken at random the agent wanders instead, and it needs about 150 moves on average to reach the goal from the start. Within eight moves of the goal it takes the fewest moves from all 28 starts, and a tie breaks its way at one more, 29 of 80.

A never-updated estimate acts as a move that ends the episode

Why −1, and why only from nine moves out? As in the argument for SARSA and Q-learning, the estimates stop moving when each one equals its target, here with no average to take. Write Q0 for the value every illegal estimate keeps. Every state has an illegal move, so the agent whose target runs over all six can rest only where each legal pair satisfies the equation below.

This is the Bellman optimality equation for action values on a changed puzzle, one where every state also offers a move that ends the episode and pays Q0. A designer gets that puzzle by making step end the episode on an illegal move and pay Q0, in place of the no-op. Q0 is the same in every table, so the max stays a non-expansion, as in value iteration: |max(Q0, x) − max(Q0, y)| is never more than |x − y|. So the right side still shrinks the largest difference between two sets of estimates by a factor of γ, and the equation has one solution, which leak.py finds by value iteration. The agent never makes the extra move. Its target still values each next state as if the agent could stop there and collect Q0.

The first lines of the output give the solution, grouped by the fewest moves to the goal. With Q0 = 0 inside every max, no target short of the goal can fall below −1 + 0.9 × 0 = −1. Out to eight moves the solution still matches v*. Each of those states has a move into the goal or to a state worth at least 0.63, more than Q0, so its best target is already above −1. From nine moves out every next state is worth less than 0, so Q0 wins every max and every legal move's target is exactly −1. The five runs with the target over all six end 0.002 from this resting point on average. For the masked target the resting point is q* itself, so its rows give the same error twice. A never-updated estimate changes the values exactly where it beats the next state's best legal value.

So the never-updated estimates do no harm when Q0 sits below every value the estimates can take, even in a target over all six. Paying −1 forever is worth −1/(1 − 0.9) = −10. If every estimate starts at −10, each target is at least −1 + 0.9 × (−10) = −10, so no legal estimate ever falls below the never-updated ones. The last rows of the output test this, changing only the initial estimates. The target over all six then picks the same value as the masked target at every update, and the two agents' tables are identical. Masking the target remains the fix, since picking a low enough start needs a lower bound on every value in advance. After 5000 episodes both agents that start at −10 are also still 0.33 from q*, and they take the fewest moves from about 70 of the 80 starts. With more episodes both reach all 80.

Problems

1. An agent ignores the mask on hanoi.py. It explores all six moves, so its illegal moves are the no-ops of step, and its target takes the max over all six. Where do its estimates rest?

Answer

Every move it makes gets updated, so no estimate stays at its initial value. A no-op from s settles at −1 + 0.9 v*(s), the value of a wasted move. That is below v*(s) whenever v*(s) is above −10, as every value here is, so the max over all six lands on a legal move and the agent learns q*.

2. A designer makes every illegal move end the episode with reward 0, and the agent ignores the mask. What does its greedy agent do at the start, and from which states does it do the same?

Answer

An ending move's target is its reward, so each illegal estimate settles at exactly 0. The legal estimates then satisfy the equation above with Q0 = 0, and they settle where the agent that masked only its choice settled. At the start both legal estimates are −1, so the greedy agent makes an illegal move and ends the episode at once. It does the same wherever the best legal estimate is below 0, in the 54 states eight or more moves from the goal.

The takeaway

In the four-disk Tower of Hanoi, Q-learning that masked only its choice settled every legal estimate nine or more moves from the goal at −1, and its greedy agent looped beside the start. Masking its target as well, it solved the puzzle in 15 moves. A move the agent never makes keeps its initial estimate, and a max over all actions still reads it. The target then values each next state as if the agent could end the episode there and collect that estimate, which changes every value where the estimate beats the next state's best legal value. When legality depends on the state, mask both places: the choice, random or greedy, and the max over the next state's moves.
