# opinion

An opinion states one documented position on the first screen. Open with a
Position note that names the stance and cites the people whose record supports
it. The title and dek introduce the question or consequence without repeating
the stance.

Build each argument section from the record. In the counter section, state the
strongest opposing case in terms its holders would recognize, cite them, then
answer it. Close with the judgment the argument supports and, when possible,
what evidence would change it.
